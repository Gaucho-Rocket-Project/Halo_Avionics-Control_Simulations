# REQ009 — One params dict

`RocketSim`, `Controls`, and `Runner` take one params dict. Each value is copied onto the object, so a run does not write back into the caller's dict.

`parameters.py` holds `halo_params` and `halojr_params`. `RocketScript.ipynb` and `dashboard.py` import those dicts. `RocketSimTest1.ipynb` and `RocketSimTest2.ipynb` are removed.

`State0` is 12 kinematic values. `Runner.solve` appends `m0` and rejects any other length. 

`tests/hash_tests/run.py` passes a 12-element `State0`. The saved flight hash is unchanged.
